BHAIYA BIRTHDAY WEBSITE - SETUP

1. Open index.html in a browser.

2. Replace photos in:
   assets/images/

   Keep these same file names:
   bhaiya-main.jpg
   photo1.jpg
   photo2.jpg
   photo3.jpg
   photo4.jpg
   photo5.jpg
   photo6.jpg

3. Add your birthday song:
   assets/music/birthday-song.mp3

4. Add your surprise video:
   assets/video/surprise-video.mp4

5. Change Bhaiya's name:
   Open index.html and find:
   <h3 id="brotherName">My Dear Bhaiya</h3>

6. Change birthday date:
   Open script.js and find:
   const birthdayMonth = 9;
   const birthdayDay = 11;

   Example:
   January 5 = month 1, day 5
   December 25 = month 12, day 25

7. Edit the emotional letter:
   Open index.html and search:
   Dear Bhaiya,

8. Upload to GitHub:
   - Create a new repository
   - Upload index.html, style.css, script.js and the assets folder
   - Go to Settings > Pages
   - Under Build and deployment choose "Deploy from a branch"
   - Select main branch and /root
   - Save
